# 隐私与本地存储

[返回首页](../README.md) · [安装与连接](INSTALLATION.md)

本文描述当前客户端实现，不替代你所连接的 Freqtrade 服务、反向代理或设备系统自身的存储规则。

## 数据保存位置

| 数据 | 客户端处理方式 |
| --- | --- |
| API 密码 | 连接时用于登录，不写入工程、配置、日志或磁盘；成功连接后清空表单中的密码 |
| 访问令牌与刷新令牌 | 保存到设备 Keychain，使用 `WhenUnlockedThisDeviceOnly` |
| 服务器名称、URL、用户名 | 保存在 App 的 UserDefaults 中，供下次连接使用 |
| 外观、日期范围、图表金额 / 百分比选择、活跃服务器 | 保存在本机 UserDefaults 中 |
| 账户指标、持仓、已平仓历史 | 作为快照保存在 App 缓存目录，按服务器配置 ID 分文件，使用完整文件保护 |
| 区间统计与图表坐标 | 保存在内存中；历史变化、服务器切换或跨 UTC 日时失效 |

缓存是包含账户数据的本地文件，不是无内容的占位符。系统可以回收缓存，不能将其视为交易记录备份。切换到演示模式不会自动删除之前保存的服务器配置或令牌。

## 网络通信

客户端向用户配置的 API 地址请求数据，没有接入广告、第三方分析或遥测 SDK。认证和请求使用原生 URLSession；临时会话不使用持久化 URLSession 响应缓存，App 的快照缓存由自身管理。

HTTPS 使用系统 TLS 校验，不接受任意证书。客户端拒绝 HTTP 重定向，应直接填写最终 API 地址。

为了兼容自部署服务，App 允许 HTTP；HTTP 不提供传输加密，登录信息、令牌和交易数据可能以未加密流量传输。需要加密时请配置并使用有效的 HTTPS 地址。

## 历史清理的影响

历史清理会修改你连接的服务器数据库，既不是本机“清缓存”，也不会撤销交易所中已成交的交易。删除前展示预览并要求确认，逐笔核对交易状态后执行。

本机旧快照在第一笔删除前清除，完成或停止后重新同步，避免删除后的旧记录从缓存重新出现。更多行为见 [使用指南](USER_GUIDE.md#历史清理)。

## 截图与反馈

公开仓库的图片均来自演示模式，图片中的金额、仓位和收益不是实际账户表现。公开的测试使用本地夹具与模拟网络，不包含真实账号或服务器缓存。

提交 Issue、日志或截图时，请移除密码、令牌、个人服务器地址、账户数据及设备标识。总览的金额隐藏按钮只是临时显示开关，不能保证整张截图中的所有隐私内容都被遮挡。
